# Fusion Compute CIMD test client

Public OAuth client metadata controlled by engdahlz for an Autodesk Fusion Compute MCP admission test. No secrets are stored here. This is an independent test client, not an OpenAI or Autodesk application.

Metadata URL: https://engdahlz.github.io/fusion-compute-cimd/client.json

Native public client, authorization code with PKCE, refresh tokens, no token endpoint client authentication. Loopback redirects use the Codex Fusion Compute callback path. OAuth clients select the local listening port at runtime. Publication does not imply Autodesk approval or successful OAuth.
